# 第一版開工規格閘門

日期：2026-09-01  
結果：通過

## 已定案並實作

- 計算契約：`calculation-contract-v0.1`。
- 每月時間軸及固定事件順序。
- 有效年利率月化及實質／名目換算。
- 家庭可用資產範圍與共同資產只計一次。
- 每月投入目的地與停止規則。
- 退休期間不得出現資金缺口，期末滿足安全準備金與遺產目標。
- Error 阻止計算、Warning 不阻止有效資料計算。
- SHA-256 輸入雜湊及逐月輸出追溯。
- IndexedDB Repository 邊界與版本化 JSON 備份。

## 第一版工程決策

- 資產依 Return Profile 分桶計息，退休支出按可用餘額比例提領。
- 未到 `availableFrom` 的資產不計值、不推估報酬，到期月份月初加入保存價值。
- 計算基準日保存於規劃資料，避免重新開啟時無聲改變歷史結果。
- 非 TWD 資產第一版不直接輸入計算；日後由應用層匯率轉換模組處理。
- 最早退休結果只針對主要規劃人；A／B 切換是資料範圍檢視。

## 可延後、不阻礙第一版

- 勞保、勞退、國民年金完整規則。
- 稅務與交易成本。

- 不動產出售、負債攤還與一次性收入操作介面。
- Monte Carlo、AI、雲端同步及多裝置衝突處理。
