# 第三階段實際修正內容說明書：Mobile First 全站操作體驗

**完成日期：2026-09-10（台北時間）**
**目標版本：公版（PUBLIC）**
**工作分支：`public/stage-three-mobile-first`**
**部署目標：Cloudflare Pages `retirement-planner-public`／`preview` 分支**
**驗收網址：<https://preview.retirement-planner-public.pages.dev/>**

## 1. 執行範圍

本次依第三階段施作方案完成公版 Mobile First 重構。修改集中在導航、資訊層級、表單揭露方式、觸控尺寸、表格與圖表的行動版呈現，以及跨尺寸／跨瀏覽器測試。資料模型、計算引擎、財務公式與本機資料格式均未修改。

私版未納入本次修改、提交或部署。公私版 UI 一致性須在後續私版獨立任務實作並驗證，避免公版內容越界部署至私版專案。

## 3. 實際修正內容

### 3.1 導航與可及性

- 行動版底部導覽固定五個入口：`預測`、`資產`、`投資`、`情境`、`更多`。
- `更多`包含退休制度、行情更新、預測設定與資料備份。
- 目前頁面同時以 `aria-current="page"` 標示於桌面與行動導航。
- 切換功能後回到頁首，鍵盤／輔助科技焦點移至 `main-content`。
- Bottom Sheet 支援背景點擊、Escape 與關閉按鈕。

### 3.2 共用 Mobile First 規則

- 900px 以下使用底部導航、單欄主要內容及卡片化寬表格。
- 主內容與底部操作列納入 `safe-area-inset-*`，避免被瀏海或 Home Indicator 遮住。
- 輸入欄位在行動版使用 16px 字級，避免 iOS 聚焦時自動放大。
- 表單控制、一般與小型按鈕最小高度 48px；圖示按鈕為 48×48px。
- Checkbox／Radio 可視控制放大至 24px，整列操作區至少 48px。
- 手機表單操作列改為全寬按鈕；小螢幕時改為單欄排列。
- 保留既有 `prefers-reduced-motion` 規則，並停用趨勢折線動畫。

### 3.3 各頁面修正

- **首頁／預測**：核心金額優先、詳細組成收合；預測表格與情境比較表在手機和平板改為卡片；圖表軸標與動畫調整。
- **家庭資料／資產**：基本欄位先顯示，投資預測與行情預設收合；可追蹤商品會自動帶入行情流程；資產與投入的儲存操作適合拇指操作。
- **投資組合**：升為底部主要入口；資產勾選、比例欄位與儲存按鈕擴大觸控區。
- **情境模擬**：常用快速方案保留，進階變因分組收合，結果改為可讀的期間卡片。
- **勞保／勞退**：兩套制度分開收合，摘要直接顯示啟用狀態，官方來源連結具備足夠觸控高度。
- **預測設定**：維持既有報酬預設 Accordion，修正窄螢幕摘要排版並加入黏附式儲存操作。
- **行情更新、備份／還原**：沿用相同單欄、觸控與安全區規則；功能入口集中於 Bottom Sheet。
- **首次使用流程**：縮短手機首屏介紹區，讓主要選擇更早進入可見範圍。

## 4. 共用邏輯與資料安全

- 桌面、平板與手機使用同一組 React 元件、資料來源與計算服務。
- 沒有建立手機專用財務邏輯或第二套資料流程。
- 沒有修改 IndexedDB 名稱、備份格式、報酬計算、退休制度公式或市場資料整合。
- 展示資料仍不寫入正式本機資料；既有離線與備份流程保持有效。

## 5. 驗證內容

自動化驗證涵蓋：

- ESLint 全專案靜態檢查。
- Vitest：20 個測試檔、98 項單元／整合測試。
- Playwright：桌面 Chrome、Pixel 7 Chrome、768×1024 觸控平板 Chrome、iPhone 13 WebKit。
- 手機直向 375×667、手機橫向 844×390、根字級放大至 20px。
- 底部五項導覽、Bottom Sheet、目前頁標示與切頁焦點。
- 觸控高度、iOS 表單字級、資產漸進式揭露及頁面級水平溢位。
- 首頁、資產、投入、投資組合、情境、退休制度、設定、行情、備份與首次使用流程。
- PWA Service Worker 離線重新開啟於 Chrome 桌面、手機與平板執行；Playwright WebKit 不提供可用的 Service Worker 離線測試環境，因此 Safari 相容性由其餘介面與資料流程測試覆蓋。

## 6. 驗收準則

- 375px 直向及 844px 橫向放大文字時，文件本身不產生水平溢位。
- 常用四項功能可由底部一鍵進入，其餘功能可由拇指可達的 Bottom Sheet 進入。
- 核心表單可在手機上完成，必要操作區不小於 44px，實作目標為 48px。
- 預測與情境資料在手機／平板改為卡片閱讀，不以縮小文字容納寬表格。
- 核心金額與今天購買力先顯示，組成與資格由使用者選擇展開。
- 桌面保留側邊欄與多欄配置，功能與計算結果不因響應式呈現改變。

## 7. 部署核對項目

部署完成後依專案規則核對：

1. Cloudflare Pages project 為 `retirement-planner-public`。
2. 部署 branch 為 `preview`。
3. deployment source commit 與推送至 `preview` 的 Git commit 一致。
4. `https://preview.retirement-planner-public.pages.dev/` 的 `build-version.json` 載入相同 commit。
5. 指定網址可實際載入首頁並顯示公版名稱。
