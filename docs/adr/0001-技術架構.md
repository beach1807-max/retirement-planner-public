# ADR 0001：第一版技術架構

狀態：已採用  
日期：2026-09-01

## 決策

- 前端採 React、TypeScript 與 Vite，輸出純靜態資產。
- PWA 採 `vite-plugin-pwa` 產生 Manifest 與 Service Worker。
- 財務資料以 IndexedDB 儲存，使用 Dexie 實作 Adapter。
- 財務金額與利率計算使用 `decimal.js`，避免二進位浮點數累積誤差。
- 輸入邊界以 Zod 驗證；計算核心只接收已驗證的純資料物件。
- 單元與元件測試採 Vitest 與 Testing Library。
- Cloudflare Pages 僅部署靜態程式，第一版不接收或同步使用者財務資料。

## 理由

此組合能用最少的伺服器端複雜度完成離線 PWA、型別安全、可測試計算核心與 IndexedDB。本機優先也符合第一版隱私邊界，並保留日後以 Repository Adapter 接上雲端儲存的能力。

## 部署設定

- GitHub 預設分支：`main`
- Cloudflare Pages 建置命令：`npm run build`
- 輸出目錄：`dist`
- Node.js：由 `.nvmrc` 固定為 `22.16.0`
