# ADR 0009：官方手動行情與快取

- 狀態：已採用
- 日期：2026-09-03

## 決策

第一版只在使用者主動觸發時，透過可替換 `MarketDataProvider` 取得資料。Cloudflare Pages Function 代理臺灣證券交易所 `STOCK_DAY_ALL` 的上市股票／ETF 收盤價，以及中央銀行 `BP01D01` 的主要通貨對美元日匯率，換算為每單位外幣兌 TWD。

行情批次保存標的、價格、匯率、資料日、來源、抓取時間與成功／部分成功／失敗 stamp。更新資產市值後，總資產、Portfolio、再平衡及退休預測由同一份 `PlannerData` 重算。部分或整批失敗都保留上一筆有效值；超過 7 天顯示過期提醒。

行情與匯率快取納入 JSON 備份，讓離線規劃可重現，但 UI 不會宣稱離線快取為最新。Domain 與 Calculation Engine 不含 HTTP、API key 或供應商程式。

## 範圍

第一版官方報價限 TWSE 上市股票與 ETF。多市場、即時、自動排程、交易與個別證券建議均不在本版。
