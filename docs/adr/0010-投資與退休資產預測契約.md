# ADR 0010：投資與退休資產預測契約

日期：2026-09-05  
狀態：已接受  
契約版本：`projection-contract-v0.2`

## 決策

- Dashboard 以目前投資配置、固定期間資產預測與退休制度資訊為主；總資產、總負債與淨資產摘要改放家庭資料。
- 預測固定輸出計算基準日 10、15、20、25、30、35 年後的結果，不搜尋或建議退休年齡。
- 每個期間輸出保守、穩健、樂觀三種情境。三者共用本金與投入計畫，分別在各資產原年化報酬率上調整 -2、0、+2 個百分點；最低年化報酬率限制為 -99%。
- 每個結果同時輸出未來名目金額及依使用者通膨假設折算的今天購買力。
- 投資預測只納入投資組合明確選取的資產與明確投入。完整資產總額不等於投資預測本金。
- 商品類型與投資配置分類分開保存。配置分類固定為股票、債券、貨幣市場、現金及其他；ETF 與基金由使用者依實際內容分類。
- 勞保老年年金視為退休收入，與資產預測分開顯示。
- 勞退專戶從目前餘額、雇主提繳、自提及報酬率逐月累積，納入資產預測並分項呈現。到預估請領月份後保留該時點餘額，不推測提領、消費或再投資行為。
- 原 `calculation-contract-v0.1` 保留作為舊退休可行性試算與歷史結果追溯，不再作為 Dashboard 的主要輸出。

## 固定期間輸出

每個情境與期間至少包含：

```text
yearsFromNow
month
investmentAssetsNominal
laborPensionAssetsNominal
totalAssetsNominal
totalAssetsReal
```

預測結果必須保留契約版本、計算基準日、通膨率、納入資產 ID、排除原因及資料缺漏提醒。

## 邊界

- 收入與未配置現金流不會自動轉成投資投入，避免與 Contribution 重複計入。
- 負債保留在完整資產管理與淨資產摘要，不從投資資產預測中自動扣除。
- 勞退請領後的提領與資金用途未建立設定前，不納入本契約推測。
- 情境是固定報酬假設試算，不代表機率、承諾或退休建議。

## 2026-09-05 檢視與請領模式擴充

- 首頁預設 10 年後，以選單切換期間，可展開全部；預測引擎仍輸出完整六個期間。
- 可依整體、資產類別或單筆資產預測；篩選的投入只納入明確指定對應資產者，勞退只屬整體。配置比例仍用整體分母。
- 可選擇第四個自訂情境，在原年報酬上加減百分點，另有是否同步調整勞退的開關；原三種結果不變。
- 勞退模式以選填欄位 claimMode 儲存，舊備份可繼續讀取；月領與一次領影響請領分析，不改變固定期間資產累積口徑，不重複累計月領收入。
