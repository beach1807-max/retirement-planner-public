# ADR 0007：投資組合與再平衡邊界

- 狀態：已採用
- 日期：2026-09-03

## 決策

投資組合只保存使用者明確選定的資產 ID、資產類別目標比例與允許偏離，不保存可由資產市值重建的實際配置。家庭層級資產每筆只計一次；不動產、保險與退休專戶不會自動成為可再平衡資產。

獨立 `Rebalancing Engine` 只接收分類市值、目標比例及偏離門檻，不依賴 UI、IndexedDB 或網路。結果只說明配置是否偏離，不給出個別證券買賣建議，也不執行交易。

## 理由

這可避免總資產與可投資範圍混用，也讓階段七的行情更新以同一批市值重新衍生實際配置而不產生重複資料。
