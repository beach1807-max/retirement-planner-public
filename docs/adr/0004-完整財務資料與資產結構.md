# ADR 0004：完整財務資料與資產結構

日期：2026-09-02  
狀態：已接受

## 決策

- Planner schema 升為 `planner-data-v0.3`，備份升為 `retirement-planner-backup-v0.3`；v0.1、v0.2 仍可匯入並遷移。
- 新增 Income、Expense、Liability、Account 與 Holding。收入只保存收入事實，不會自動轉成 Contribution。
- Liability 第一版保存房貸、信貸、車貸與其他負債的目前餘額及平均月還款；完整攤還表延後。
- Account 與 Holding 建立 `Account → Holding → Asset` 關聯。刪除帳戶會同步移除其 Holding 並解除 Asset 關聯；刪除 Asset 會移除其 Holding，避免孤兒資料。
- Asset 分類擴充現金、股票／ETF、債券、基金、保險、不動產、退休帳戶及其他，並可保存地區、風險分類、所屬帳戶與基本不動產地址。
- Income、Expense、Liability、Account 與 Asset 共用 individual／joint／household 歸屬；共同持分沿用合計 100% 的驗證。
- 新模組一律使用 provided／notProvided／notApplicable；明確 0 仍是 provided，不視為缺漏。
- 家庭與個人摘要由 Planner Service 依所有權及持分計算總資產、總負債與淨資產。家庭共同項目只計一次；家庭層級項目不分配到個人摘要。

## 相容性

`toCalculationInputV01()` 只把既有退休資產與明確 Contribution 送入 `calculation-contract-v0.1`。新增收入、支出、負債、帳戶與 Holding 不會靜默改變既有退休結果；它們將在階段三透過新的 Projection 契約進入完整月份時間軸。
