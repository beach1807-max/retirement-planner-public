# ADR 0005：完整家庭預測契約

日期：2026-09-02  
狀態：已接受

## 決策

- 保留 `calculation-contract-v0.1` 的反向最早退休搜尋與事件順序，另建 `projection-contract-v0.1` 負責完整家庭預測及 Dashboard 指標。
- 指定退休月份為主要規劃人的 `plannedRetirementMonth`。正向試算會在該月份停止 owner／primary retirement 類型投入，並提供當月名目與實質退休資產。
- 退休目標資產以既有 v0.1 的固定實質生活費、一次性支出、安全準備金、遺產目標、通膨及基準報酬率，從規劃終點逐月反推至預計退休月份；顯示值換算為該月份的今天購買力。
- 準備率為「預計退休月份的實質退休資產 ÷ 同月份實質退休目標資產 × 100%」。目標為 0 時顯示「已達標」，不顯示無限百分比。
- Income、一般 Expense、Liability 還款與明確 Contribution 進入同一月份現金流摘要。收入扣除支出、還款及投入後只形成未配置現金流；系統不把收入自動加入退休資產，因此不會與 Contribution 重複計入。
- 負債第一版按目前餘額及每月還款線性遞減，不臆測利率或攤還結構；完整負債預測日後另建契約版本。
- Dashboard 可切換名目／實質金額，顯示 50、55、60、65 歲節點、目前淨資產、資料更新時間與完整度。家庭／個人範圍仍只改變目前摘要，退休結果維持家庭語意。

## 警示

- `notProvided` 的收入、支出或負債會產生具名 Warning；`provided = 0` 與 `notApplicable` 不視為缺漏。
- 若明確投入高於收入扣除一般支出與負債還款後的餘額，產生負現金流 Warning，但不自行修改使用者輸入。
