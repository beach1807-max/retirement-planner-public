# ADR 0011：臺美股日收盤價與免費美股金鑰

日期：2026-09-11  
狀態：已接受

## 決策

- 行情用途只採已完成交易日的收盤價，不提供即時、盤中或延遲報價。
- 上市與上櫃收盤價分別取自 TWSE、TPEx 官方 OpenAPI；USD/TWD 取自中央銀行公開資料。
- 美股使用 StashGamma 免費 EOD API，採使用者自備免費 API key（BYOK）。
- 美股 API key 只存放於使用者瀏覽器的 `localStorage`，不寫入 PlannerData、IndexedDB 財務資料、JSON 備份、Git 或 Cloudflare。
- 美股請求由瀏覽器直接送往資料供應商；Pages Function 不接收、記錄、快取或轉送使用者 API key。
- 未設定金鑰、額度用罄或來源失敗時，保留上次有效行情與手動市值，不以零值覆蓋。

## 理由與限制

- 免費方案需由每位使用者自行註冊取得金鑰；公版無法代替使用者建立第三方帳號。
- 免費額度目前為每小時 300 次、每日 800 次、每週 4,000 次；公版採手動更新及逐標的請求。
- 金鑰不隨備份移轉；更換瀏覽器或裝置時需重新設定。
- 資料來源與免費方案可能變更，介面須顯示來源與資料日期，不宣稱為即時行情。
