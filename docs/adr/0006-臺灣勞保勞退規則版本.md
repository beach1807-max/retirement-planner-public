# ADR 0006：臺灣勞保／勞退規則版本

日期：2026-09-02  
狀態：已接受  
規則版本：`tw-labor-rules-2026-08-20`

## 官方依據

- 勞保老年年金兩式擇優、最高 60 個月平均投保薪資、每提前／展延一年減／增 4%（最多 20%）：<https://www.bli.gov.tw/0004857.html>
- 2026 年起法定請領年齡為 65 歲；1957 年及以前至 1962 年及以後的出生年齡對照：<https://www.bli.gov.tw/0017389.html>
- 勞退月退休金的年金生命表、整數平均餘命、期初年金現值因子與現行利率 1.1473%：<https://www.bli.gov.tw/0018437.html>
- 勞退年滿 60 歲、提繳年資滿 15 年可選月領或一次領；未滿 15 年一次領：<https://www.bli.gov.tw/0008222.html>
- 雇主提繳不得低於每月工資 6%，勞工自願提繳上限 6%：勞工退休金條例第 14 條。

查核日為 2026-09-02。新規則只能新增版本，不得修改本版本後重算歷史結果。

## 計算邊界

- 勞保老年年金須有最高 60 個月平均月投保薪資、年資與請領年齡；年資未滿 15 年不猜測年金，提示另行確認一次給付。
- 勞保提前或展延未滿一年依月數比例調整，最多前後五年。
- 勞退專戶從目前本金與收益開始，按使用者輸入的月提繳工資、雇主／自提率與預估報酬逐月累積；此報酬是規劃假設，不是法定保證收益。
- 勞退月領依 111 年全國簡易生命表之整數平均餘命與 1.1473% 年利率計算首期月退休金。規則資料至少每三年可能調整，因此結果保存規則版本。
- 每位家庭成員獨立估算。成功的月領結果以外部退休收入事件併入同一家庭 Projection，不相加兩份退休資產結果。
- `notProvided` 只阻止該成員退休制度估算；`provided = 0` 與 `notApplicable` 保持不同語意，不影響其他有效資料。
- UI 固定顯示「估算，實際資格與金額以主管機關核定為準」。
