# ADR 0002：第一版暫定決策

狀態：已採用，可在新契約版本替換  
日期：2026-09-01

## 不阻礙開工的決策

1. `availableFrom` 到期前資產不參與退休可用餘額，也不由第一版引擎推估其報酬；到期月份月初以保存的 TWD 價值加入。
2. 各資產依自己的 Return Profile 逐月計息；沒有 Profile 的可退休資產使用退休方案的預設 Profile。
3. `planningEndAge` 以主要規劃人達到該歲數的生日月份月底為規劃終點。
4. 年化報酬率必須大於 -100%；第一版合理輸入範圍為 -99% 至 100%，超出視為 Error。
5. `inputHash` 使用鍵名排序後的標準化 JSON，再以 SHA-256 計算。
6. 非 TWD 資產必須先有有效匯率及匯率日期；否則應用層阻止計算。
7. 第一版只計算主要規劃人的最早退休月份；家庭、主要規劃人、伴侶切換用於結果範圍與資料完整度檢視。

## 尚未納入

完整勞保／勞退、稅務、交易成本、即時行情、雲端同步、伴侶獨立退休年齡及 Monte Carlo 留待後續模組。
