# 待後續協助與擴充

以下項目不阻礙第一版上線，但進入對應階段時需要產品決策、個案資料或外部服務：

## 需要產品決策

- 伴侶獨立退休年齡及家庭完全退休時間的呈現方式。
- 不動產出售、房貸攤還與一次性收入的輸入體驗。
- 退休後分階段生活費及醫療／長照支出模型。
- 是否公開免費、收費訂閱或僅供個人使用。

## 需要使用者個案資料

- 實際勞保年資、最高 60 個月投保薪資及預計請領時間。
- 勞退新／舊制、專戶餘額、雇主提繳及個人自提率。
- 國民年金、軍公教、農保、特殊工作或已領一次給付等情況。

## 需要外部帳號或授權

- 股票／ETF／匯率行情 API 及合法顯示、快取與轉供授權。
- 自訂網域及 Cloudflare DNS 設定。
- 雲端同步使用的身分驗證、資料庫及加密金鑰。

## 正式商用前

- 個資告知、服務條款、資料安全與事故應變流程。
- 確認功能及文案不構成未經許可的個別證券投資顧問服務。
- 臺灣法規規則資料的來源、生效日期、版本及定期複核責任。
