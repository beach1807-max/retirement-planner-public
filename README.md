# 安心退休規劃 PWA

以主要規劃人為核心、同時整合家庭可用資源的退休資產規劃工具。第一版回答：

1. 依目前資料與假設，最早約在什麼月份可以退休？
2. 退休時與規劃終點約有多少資產？

## 第一版功能

- 建立家庭、主要規劃人與選配伴侶。
- 建立現金、股票／ETF 與其他退休資產。
- 設定資產為個人使用、家庭退休可用或排除。
- 建立每月投入與投入停止規則。
- 按月計算最早退休月份、退休時資產與規劃終點資產。
- 家庭／主要規劃人／伴侶三種資料檢視。
- IndexedDB 本機儲存及版本化 JSON 備份還原。
- 可安裝、可離線重新開啟的 PWA。

第一版不包含完整勞保／勞退、稅務、交易成本、即時行情、Monte Carlo 或雲端同步。

## 隱私邊界

Cloudflare Pages 只提供靜態 HTML、CSS、JavaScript 與 PWA 資產。家庭財務資料留在使用者目前瀏覽器的 IndexedDB，不會傳送到 GitHub 或 Cloudflare。

清除瀏覽器網站資料或更換裝置可能遺失規劃，請定期使用「備份還原」匯出 JSON。

## 本機開發

需求：Node.js 22.16.0 或以上版本。

```bash
npm install
npm run dev
```

完整驗證：

```bash
npm run check
npm run test:e2e
```

- `npm run check`：ESLint、14 項單元／整合測試、TypeScript 與正式建置。
- `npm run test:e2e`：使用系統 Chrome 執行桌面與行動版操作、IndexedDB、備份、響應式及離線 PWA 測試。

## Cloudflare Pages

正式建置命令為 `npm run build`，輸出目錄為 `dist`。直接部署：

```bash
npm run build
npm run deploy
```

預覽分支部署：

```bash
npm run deploy:preview
```

詳細設定見 [部署手冊](docs/部署手冊.md)。
